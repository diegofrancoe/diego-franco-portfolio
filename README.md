# Portfolio Web | Diego Franco Echeverri

Portafolio personal de Diego Franco Echeverri: productos digitales, IA aplicada, automatización e integraciones.

## Desarrollo local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

El proyecto está preparado para desplegarse en Vercel desde la raíz del repositorio. La configuración de producción conserva las rutas directas de perfil, contacto y casos de estudio.

Dominio de producción: `https://www.diegofrancoe.com`.
